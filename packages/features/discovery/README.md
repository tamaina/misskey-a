# discovery

ノート検索、ユーザー検索、設定検索、照会、みつける、ハッシュタグ、オートコンプリート（ユーザー、ハッシュタグ、絵文字、MFM）。

設定検索の項目づくりと検索・補完を担当する。設定画面の配置と移動は navigation、設定値の保存は preferences、絵文字の一覧と検索は emojis、MFMの構文は markup が担当する。

`frontend/` は画面とブラウザの処理を置く。`backend/` はサーバー側の処理を置く。`contract/` はAPIの入力・出力と公開する型を置く。

`frontend/embed/` は外部サイトへの埋め込みで使う、この機能の画面とブラウザの処理を置く。通常の画面とは起動・設定・翻訳を分ける。
