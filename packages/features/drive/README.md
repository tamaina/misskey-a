# drive

ドライブ、ファイル・フォルダーの一覧と管理、アップロード、圧縮、センシティブ設定、ウォーターマーク、画像のフレーム、ドライブの整理。

画像・動画・音声の表示と加工、プレビュー、Blurhash、メディアプロキシ、センシティブなメディアの検出、画像の合成。ブラウザで表示できるファイルの種類と、画像処理のWorkerも担当する。

`GET /drive/:fileId` と `HEAD /drive/:fileId` は、本人のローカル保存済み原本を取得する入口。
既存の Bearer 認証を使い、アプリトークンには `read:drive` が必要。URL や Cookie の認証情報は受け付けない。
応答は `private, no-store` の添付ファイルで、第三者所有・未検出・未対応の保存先はいずれも 404。
最初の実装は内部ストレージのみで、オブジェクトストレージ、遠隔ファイル、Range、アーカイブ、ブラウザー UI は後続。
従来の `/files`、`/proxy`、公開 URL は変更しないため、この入口の認可は既存ファイルを非公開化するものではない。
