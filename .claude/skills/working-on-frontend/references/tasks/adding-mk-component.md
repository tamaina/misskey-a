# コンポーネント変更

コンポーネントは `packages/features/<feature>/frontend/` の既存配置に合わせる。共有 UI の `Mk*` 命名は近い実装を参照する。
近い既存コンポーネントを参照し、[SFC・a11y](../knowledge/component-conventions.md) の注意点を確認する。
共有コンポーネントには [Storybook](../knowledge/storybook.md) の story を併設し、変更した状態・操作を確認する。
検証は [frontend-testing.md](../knowledge/frontend-testing.md) と [shipping-misskey-change](../../../shipping-misskey-change/SKILL.md)。
