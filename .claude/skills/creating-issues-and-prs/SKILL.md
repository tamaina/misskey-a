# Issue / PR

[AGENTS.md](../../../AGENTS.md) の権限・Issue 先行方針に従う。
起票前に重複を検索し、[Issue テンプレート](../../../.github/ISSUE_TEMPLATE/) と [PR テンプレート](../../../.github/pull_request_template.md) を使う。
PR の対象は `develop`。対応 Issue をリンクし、変更理由と検証結果を簡潔に記載する。該当しない checklist を無理に埋める必要はない。

一般の投稿規約は [CONTRIBUTING.md](../../../CONTRIBUTING.md)。脆弱性は通常の Issue / PR で公開せず、[非公開の報告窓口](https://github.com/misskey-dev/misskey/security/policy) を案内する。
